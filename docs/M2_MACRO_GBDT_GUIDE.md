## 0. この資料の歩き方

M-2 がやりたいことを一言でいうと、次の通りです。

> **「財務の数字と経済全体の風向き（マクロ）から、各社の 52 週先のリターンを予測する。
> 予測には、小さな『はい／いいえ』の質問を重ねた木を何百本も足し合わせる方法（勾配ブースティング）を使う」**

そして M-2 の価値は、予測そのものより**比べられること**にあります。M-1（直線で予測するモデル）と
**同じデータ・同じ物差し**で並べ、どちらの作り方が当たるのかを、使う人が自分の目で確かめ続けられるように作ってあります。

## 1. そもそも何を作りたいのか

### 1-1. M-1 の「非線形の兄弟」

M-1 は、財務の数字（PBR・ROE など）に**係数を掛けて足す**、つまり直線（線形）で将来のリターンを予測します。
分かりやすい反面、「PBR が低いほど良い」という関係が**どの会社にも同じ強さで**効く、と決め打ちしています。

ところが現実はもっと入り組んでいます。

> 「PBR が低い会社は割安で上がりやすい。**ただし**借金が多い会社だけは別で、低い PBR は倒産の心配の表れ」
> 「金利が上がっている年には、利益の安定した会社が見直される」

こうした「**ある条件のときだけ効く**」関係を**非線形**や**交互作用**と呼びます。M-1 でこれを扱うには、
人が「PBR × 金利」のような掛け算の項（交差項）を考えて式に足す必要がありました。M-2 は、
決定木という仕組みで**この組み合わせを自動で見つけます**（第2章）。

M-1 と M-2 は、次のものを**共有**しています。

- 予測する対象（52 週先の対数リターン）と、対象になる会社の集まり（母集団）
- リスクの軸（R2・R3・R_macro）と、リスク-リターンの散布図・効率的フロンティアの見方（M-1 の副読本の第4〜8章）
- 答え合わせの手続き（第7章）

違うのは**予測の作り方だけ**です。だから両方を並べると、「直線で足りるのか、木の柔軟さが効くのか」を同じ条件で比べられます。

### 1-2. 最終アウトプット

画面で受け取るのは、M-1 と同じ形の**リスク-リターン散布図**と**ランキング表**に加えて、
「予測が何によって決まったか」を見せる **SHAP の棒グラフ**と、銘柄ごとの内訳です（第6章）。

実際の運用では、モデルの画面の上位から**約 10 社**を買います（運用の K・[ADR-0070](adr/0070-search-selects-in-two-stages-for-top-k-buying.md)）。
この事実は、設定の選び方（第5章）にも反映されています。

## 2. 決定木と勾配ブースティング ― 「20 の質問」を何百回も

### 2-1. 決定木：はい／いいえの質問で予測する

**決定木**は、「はい／いいえ」で答えられる質問を順番にたどって、答えにたどり着く仕組みです。
「20 の質問」というゲームと同じ考え方です。

```
                 PBR は 1 倍未満？
                 ／            ＼
              はい              いいえ
               │                 │
     自己資本比率 30% 以上？    ROE 10% 以上？
        ／      ＼             ／      ＼
     はい      いいえ        はい      いいえ
      │          │           │          │
   +8% と予想  −3% と予想   +5% と予想  +0% と予想
```

最後にたどり着いた箱（葉）に書かれた数字が予測です。上の例では「PBR が低くても、財務が弱ければ下がる」という
**条件つきの関係**が、木の形そのものに表れています。人が掛け算の項を考えなくても、分岐の重なりが交互作用になります。

> **木は「単位」を気にしない**：決定木が見るのは「どこで区切るか」だけなので、値を対数にしても順番が変わらなければ
> 同じ木になります。そのため M-2 は説明変数の外れ値の処理（winsorize）をせず、予測する側（リターン）の外れ値だけを
> 抑えます。ただし説明変数は、M-1 と同じく**単位のない比率・スコア**にそろえてあります（CLAUDE.md「分析モデルの次元整合性」）。

### 2-2. 1 本では粗い ― だから足し合わせる（ブースティング）

木 1 本の予測は粗く、外れも大きくなります。そこで**勾配ブースティング**では、木を 1 本ずつ順番に足していきます。

1. 1 本目の木で、ざっと予測する
2. 予測と実際の差（**残差**＝外した分）を計算する
3. 2 本目の木は、**その外した分を当てる**ように作る
4. 3 本目は、まだ残っている外れを当てる……と繰り返す

最後の予測は、全部の木の答えを足し合わせたものです。前の木の間違いを次の木が少しずつ直していくので、
1 本ずつは単純でも、合わせると細かい関係まで表せます。1 本ごとにどれだけ直すかの歩幅を**学習率**と呼び、
小さいほど慎重に（たくさんの木で）少しずつ近づきます。

M-2 は、この方法の代表的な実装である **XGBoost**（Chen & Guestrin 2016）を使っています。

### 2-3. 柔軟さの代償

木を重ねるほど細かい関係を表せますが、それは**偶然のでこぼこまで覚えてしまう**危険と表裏です（第4章）。
株の 52 週先のリターンは、財務やマクロで説明できない雑音がとても大きい（**S/N 比が低い**）ので、
柔軟なモデルほどこの危険が大きくなります。M-2 の設計の大半は、この危険との付き合い方です。

## 3. 入力 ― 何を見て予測するか

### 3-1. M-1 と同じ材料から、交差項を除いたもの

M-2 の説明変数は、M-1 と**同じ選択肢**から選びます。

- **財務**：PBR・ROE・配当利回りなどの比率
- **マクロ**：為替・金利・株価指数などの「変化」や「過去と比べた位置（Z スコア）」（考え方は M-1 の副読本の第2章）

M-1 との違いは 2 つだけです。

- **交差項を持たない**：掛け算の項は木が自分で作るので、人が用意しない
- **事前の変数選びをしない**：M-1 は統計的な基準（BIC）で使う変数を絞りますが、M-2 はどの変数で分岐するかを木に任せます

> マクロを使うかどうかの既定は、M-1 と M-2 で割れています（同じ選択肢で、既定だけが違う）。
> 選択肢の全リストと既定は、正本の [MODELS.md §11.3](MODELS.md) と `plugins/macro_snapshots.py` の `_MACRO_MAP` を見てください。

ほかに、選択肢として用意されているが**既定では使わない**ものがあります。

- **モメンタム**（「最近上がった株は上がり続けやすい」）：文献では強いとされますが、比べ方をそろえて測り直すと
  効かなかったので既定 OFF です（第7章の「母集団が縮む側は有利に見える」・[ADR-0045](adr/0045-momentum-gains-vanish-when-the-population-is-aligned.md)）
- **価格の動きの特徴量**（値動きの荒さ・出来高の急増など）：M-3 と共有する材料。検証してから既定にする方針です

### 3-2. 欠けた値をどう扱うか

データには欠けがつきものです。M-2 は欠けの種類によって扱いを変えます。

| 欠けているもの | 扱い | 理由 |
|---|---|---|
| **マクロ**（歴史の浅い系列など） | 欠けたまま残して学習する | XGBoost は欠けた値を「別の枝」として扱える。会社を捨てずに済む |
| **財務** | その行を使わない（厳しく除外） | 会社ごとの中心的な情報で、推測で埋めると別の意味になる |
| 財務のうち、**書類で「無い」と確かめた空欄** | 0 で埋める | 無配の会社の配当利回り、研究開発をしていない会社の R&D 集約度は、空欄ではなく本当に 0 だから |

最後の行は、地味ですが効きます。無配の会社は有価証券報告書で 1 株配当を「−」と載せるので、数値として読めず空欄になります。
これを空欄のまま扱うと、無配の会社が学習からまるごと外れていました。「無い」と書類で確かめたものだけを 0 にし、
株価や売上が欠けているような「本当に分からない」欠けは埋めません（詳細は [MODELS.md §11.3.2](MODELS.md)）。

> 直線のモデル（M-1）は欠けた値を扱えないので、マクロが欠けた会社はその時点で捨てるしかありません。
> M-2 が欠けに強いのは、木という仕組みの利点の一つです。

## 4. 学習のしかた ― 覚えすぎを防ぐ工夫

### 4-1. 過学習とは

**過学習**とは、学習に使ったデータの**偶然のでこぼこまで覚えてしまい**、新しいデータでは外すことです。
過去問を丸暗記した生徒が、少し問題を変えられると解けないのと同じです。

株のリターンは雑音が大きいので、柔軟な木はすぐに雑音を覚えます。M-2 は、次の 4 つの工夫で覚えすぎを抑えています。

### 4-2. 工夫①：木を小さく、慎重に（正則化）

- **木を浅くする**：質問の段数を少なくして、細かすぎる条件分けを防ぐ
- **葉に最低限の会社数を求める**：数社だけの特殊な箱を作らせない
- **使う列を木ごとに間引く**：特定の変数に頼りすぎないようにする
- **葉の値を小さめに抑える**（L1・L2 の罰則）：極端な予測を出させない
- **学習率を小さくする**：1 本ごとの直しを控えめにする

これらの強さ（ハイパーパラメータ）をどう決めるかは第5章で説明します。具体的な値の正本はコードと探索の結果です（本書には書き写しません）。

### 4-3. 工夫②：伸びなくなったら止める（早期終了）

木を足すほど学習データには合っていきますが、ある本数を超えると新しいデータでの成績は悪くなり始めます。
そこで、学習期間の**末尾の月をまるごと**検証用に取り分け、検証の成績が一定回数伸びなくなったら木を足すのをやめます。
これを**早期終了（early stopping）**と呼びます。

> **なぜ「月をまるごと」なのか**：行の番号で末尾の 20% を取ると、区切りが月の途中に落ちます。すると、
> 同じ月のどの会社が学習側・検証側に入るかが**データの並び順（会社の順番）**で決まってしまい、
> 会社が 1 社増えたり減ったりするだけで結果が変わります。月の塊で取ればこの揺れが消えます（#969）。
> 同じ理由で、木ごとに行を抜き出す処理（subsample）も止めています（#987）。
> 「**結果がデータの並び順に左右されないこと**」は、このプロジェクトが何度も確かめてきた大事な性質です。

### 4-4. 工夫③：経済の常識を守らせる（単調性の制約）

M-2 は変数選びを木に任せるので、雑音につられて「**PBR が高いほど上がる**」のような、経済の常識と逆向きの分岐を作ることがあります。
そこで、向きがはっきりしている財務比率についてだけ、**「この値が上がったら、予測は上がる（または下がる）方向にしか動かない」**
という制約を木に課せます（**単調性の制約**・monotone constraints）。

| 向き | 例 | 考え方 |
|---|---|---|
| 上がるほど予測は下がる | 割高さ（PBR・PER）、借金の重さ | 高く買うほど、将来のリターンは小さい |
| 上がるほど予測は上がる | 稼ぐ力（ROE・ROA・利益率）、配当利回り | 質の良い会社・収入の多い会社は報われやすい |
| 制約しない | マクロ、成長率、業種の中での位置など | 向きが局面によって変わる |

どの変数にどの向きを課すかの正本は `plugins/macro_gbdt.py` の `_MONOTONE_SIGN` です。制約を使うかどうかは、
第5章の探索が候補の一つとして比べます。

> 学習の後に「木が実際にどちら向きの関係を覚えたか」を測る道具（SHAP の学習方向・第6章）もあります。
> 事前に課した向きと、事後に測った向きを突き合わせれば、向きの表が妥当かを M-2 の中で確かめられます。

### 4-5. 工夫④：業種と規模を「漏らさずに」渡す

木は「素材業種ではこう、ハイテクではこう」と業種ごとに分岐できますが、業種の情報が入力に無ければ学べません。
そこで、業種を「**その業種の平均リターン**」という数字に置き換えて渡す選択肢があります（target encoding）。

ここには大きな落とし穴があります。業種の平均リターンを**採点する期間のデータも使って**計算すると、答えを少し覗いたことになります。
過去に、こうした覗き見で成績が実力以上に高く見えていたことがありました（#375）。そのため、業種の平均は
**必ず学習期間のデータだけ**で計算し、採点する期間にはその値をそのまま当てはめます。

## 5. 設定の選び方 ― 探索と「2段の選び方」

### 5-1. ハイパーパラメータを探す

第4章の「木の深さ」「学習率」「制約を使うか」などは、データから自動では決まらない**設定値（ハイパーパラメータ）**です。
M-2 は、決まった数の候補（組み合わせ）を試し、**まだ見せていないデータでの成績（OOF の rank-IC・第7章）**が良いものを選びます。
探す軸と候補の値の正本は `plugins/macro_gbdt.py` の `MacroGbdtPlugin.tuning_search_space` です。

### 5-2. 今の本番（champion）を必ず候補に入れる

「先月より点数が下がったら採用しない」というやり方は、一見安全そうで実は成り立ちません。データは毎晩伸びるので、
**先月の点数と今月の点数は、違う試験の点数**だからです（[ADR-0047](adr/0047-tuning-gate-compares-on-one-panel.md)）。

そこで、**今の本番の設定（champion）を今月の候補に混ぜて、同じデータで測り直します**。こうすれば、
選ばれる候補は必ず「同じ試験で champion 以上」になり、悪い設定に入れ替わることを構造的に防げます。

### 5-3. 乱数の種で確かめ直す

XGBoost の学習には偶然の要素（乱数）が少し入るので、**乱数の種**（偶然を再現するための番号）を変えるだけで点数が揺れます。
上位の候補どうしの差は、この揺れと同じくらい小さいことがよくあります。そこで、上位の数候補を**複数の種で回し直し、平均で選び直します**（#984）。

### 5-4. 2段の選び方 ― 上位 10 社を買う運用に合わせる

rank-IC は「**全社**を予測の順に並べたとき、実際のリターンの順とどれだけ揃うか」を測ります。
ところが実際の運用で買うのは**上位 10 社だけ**です。rank-IC がほぼ同じ候補どうしでも、上位 10 社の成績は大きく違うことがありました。

そこで、候補を 2 段で選びます（[ADR-0070](adr/0070-search-selects-in-two-stages-for-top-k-buying.md)）。

1. **1 段目**：rank-IC で 1 位の候補と比べて、**はっきり悪い**（統計的に有意に劣る）候補を外す。残った候補が「同点の集合」
2. **2 段目**：同点の集合の中で、**上位 10 社の超過リターン**（上位 10 社を買ったときに全体の平均をどれだけ上回ったか）が最も大きい候補を採る

> **なぜ「上位 10 社の成績が最大の候補」を最初から選ばないのか**：百数十の候補の中から成績が最大のものを拾うと、
> **たまたま当たった候補**を選びやすくなるからです。くじを 150 回引いて一番良い結果を「実力」と呼ぶのと同じです。
> rank-IC という安定した物差しで先に候補を絞り、その中でだけ上位 10 社の成績を使うことで、偶然に振り回されにくくしています。
> 2 段目が 1 段目の 1 位と違う候補を選び、その優位が前半・後半の両方で確かめられない状態が続いたら、2 段目をやめる規則も先に決めてあります。

### 5-5. 探索の周回 ― 空き時間で少しずつ測り切る

候補を全部試すには長い時間がかかります。そこで、平日昼間の計算の空き時間を使って、**決まった候補の集合を少しずつ測り切り**、
測り終えた時点で 1 回だけ本番の設定を入れ替える仕組みがあります（**探索の周回**・#1114）。
候補をむやみに増やさず、決まった候補を深く測ることに計算を使う、という方針です。

## 6. 出力を読む ― SHAP で中身をのぞく

### 6-1. SHAP の直感

木を何百本も足したモデルは、そのままでは「なぜこの予測なのか」が分かりません。そこで **SHAP**（Lundberg & Lee 2017）を使い、
1 社の予測を、特徴量ごとの**寄与**に分けます。

```
 全社の平均的な予測            +4.0%
   PBR が低い                 +2.5%   ← 予測を押し上げた
   ROE が高い                 +1.2%
   ドル円が上がっている         −0.8%   ← 予測を押し下げた
   借金が重い                  −1.4%
 ─────────────────────────────
 この会社の予測               +5.5%
```

足し算で予測に戻るので、「何がどれだけ効いたか」を一つずつ読めます（数字は説明のための例です）。

### 6-2. 画面で見られる 5 つの見方

| 見方 | 何が分かるか |
|---|---|
| **重要度** | 全社を通して、どの特徴量がどれだけ予測を動かしたか（大きさだけ） |
| **向き付きの重要度** | 重要度に「上げる側か下げる側か」を付けたもの。M-1 の係数の棒グラフと同じ感覚で読める |
| **学習方向** | 特徴量の値と、その寄与の相関。木が実際に覚えた向き（第4章の制約の向きと突き合わせられる） |
| **交互作用のペア** | どの 2 つの特徴量が組み合わさって効いたか。M-2 が自動で見つけた「条件つきの関係」の中身 |
| **銘柄ごとの内訳** | 上の例のような 1 社ごとの分解。ランキング表の行をクリックすると開く |

### 6-3. 確実性の軸 ― 「この予測をどれだけ信じてよいか」

M-1 は直線のモデルなので、予測のぶれ幅（R1）を式で計算できます。木のモデルにはその式がありません。
そこで M-2 は、**まだ見せていないデータで外した幅**を集めて、「外れの大きさの 90% はこの幅に収まる」という区間を作ります
（**コンフォーマル予測**・Lei et al. 2018）。全社一律ではなく、業種と規模の組ごとに区間の幅を変えます。
この幅が、売り候補を絞るときの「確実性の軸」として使われます。

### 6-4. 画面の並び

画面のランキングは、予測リターン μ からリスク R を差し引いた点数 **U = μ − λR** の順に並びます（λ はリスクをどれだけ嫌うか）。
どのリスクの軸を使い、λ をいくつにするかは、並びの成績を測って決めています（[MODELS.md §11.7.3](MODELS.md)）。
考え方は M-1 の副読本の第8章と同じです。

## 7. 本当に当たっているのか ― 答え合わせ

### 7-1. まだ見せていないデータで採点する（OOF）

答え合わせの基本は M-1 と同じです（M-1 の副読本の第11章）。時間の順を守って「学習する期間 → 採点する期間」と窓をずらし、
**採点する期間のデータを学習に一切使わない**予測だけで成績を付けます（walk-forward・OOF）。52 週先のリターンを当てるので、
学習と採点の間に**空白の期間（embargo）**を挟み、未来を覗かないようにしています。

> **柔軟なモデルほど、覗き見を吸い込んで高得点に見える**：embargo を入れる前は、M-2 の成績が実力以上に高く見えていました
> （数値は [MODELS.md §9.11](MODELS.md) の「purge の実測影響」）。成績が良すぎるときは、まず覗き見を疑います。

### 7-2. 内蔵の「直線の対照群」

M-2 は自分の中に、**同じ特徴量・同じ窓で直線のモデル（OLS）を回した結果**を持っていて、並べて出します。
両者の差がそのまま「**木の柔軟さ（非線形）がどれだけ効いたか**」です。比べる条件をそろえた対照群があるから、
柔軟さの効果を他の違いと切り分けられます。

### 7-3. 指標には役割がある

答え合わせの指標は一つではなく、それぞれ役割が決まっています（[ADR-0069](adr/0069-evaluation-metrics-have-roles.md)）。

| 指標 | 何を測るか | 役割 |
|---|---|---|
| **rank-IC** | 全社の予測の順と実際のリターンの順の揃い具合 | **主審**。採用・退役・探索の判定に使う |
| **売り側 spread** | 予測が最も低い群が、全体の平均をどれだけ下回ったか | 売りの見分けの力を測る |
| **上位 K 社の超過リターン** | 上位 K 社を買ったとき全体平均をどれだけ上回ったか | 参考。探索の中の**同点決め**（第5章）にだけ使う |
| **運用の再現** | 上位を買い、下位を売って入れ替える運用を過去の予測で繰り返した成績 | 参考。過去の道筋は 1 本だけなので判定には使わない |

> **買いが強いことと、売りが見分けられることは別物**：かつて M-2 は rank-IC で M-1 を上回るのに、売り側の指標では下回ったことがありました
> （[ADR-0022](adr/0022-short-side-oof-metric-and-default-mu-source.md)）。売り候補のランキングがどのモデルの予測を使うかは、
> 売り側の指標で選んでいます（今の既定は M-6）。

### 7-4. 「母集団が縮む側は有利に見える」

このプロジェクトでいちばん繰り返し確かめられた教訓です。ある特徴量（たとえばモメンタム）を足すと、計算に必要な過去のデータが
そろわない会社が抜け落ち、**当てにくい会社が消えた分だけ点数が上がって見える**ことがあります。

そこで、特徴量の有無を比べるときは、**両方で予測がある会社と月（共通域）だけにそろえて**測り直します。
モメンタムは、そろえると効果が消えたか逆向きになり、既定 OFF になりました
（[ADR-0045](adr/0045-momentum-gains-vanish-when-the-population-is-aligned.md)・[ADR-0050](adr/0050-hyperparameter-search-must-align-populations.md)）。
「良く見える」と「良い」を分けるための、地味ですが欠かせない手続きです。

## 8. 用語集

| 用語 | やさしい説明 |
|---|---|
| **決定木** | はい／いいえの質問を順にたどって予測にたどり着く仕組み |
| **勾配ブースティング** | 前の木の外した分を次の木が当てるように、木を 1 本ずつ足していく方法 |
| **XGBoost** | 勾配ブースティングの代表的な実装。欠けた値をそのまま扱える |
| **残差** | 予測と実際の差。外した分 |
| **学習率** | 木 1 本ごとにどれだけ予測を直すかの歩幅 |
| **非線形・交互作用** | 「ある条件のときだけ効く」関係。2 つの変数が組み合わさって効くこと |
| **過学習** | 学習データの偶然のでこぼこまで覚え、新しいデータで外すこと |
| **正則化** | 木を小さく慎重にして、覚えすぎを抑える工夫の総称 |
| **早期終了** | 検証の成績が伸びなくなったところで木を足すのをやめること |
| **単調性の制約** | 「この値が上がったら予測は上がる側にしか動かない」と木に課す約束 |
| **target encoding** | 業種のような分類を「その分類の平均リターン」という数字に置き換えること。学習期間だけで計算しないと覗き見になる |
| **ハイパーパラメータ** | 木の深さや学習率など、データから自動では決まらない設定値 |
| **champion** | 今の本番の設定。探索の候補に混ぜて同じデータで測り直す |
| **乱数の種** | 偶然の要素を再現するための番号。変えると点数が少し揺れる |
| **2段の選び方** | rank-IC で同点の候補に絞ってから、その中で上位 10 社の成績が最も良い候補を採る選び方 |
| **SHAP** | 1 社の予測を、特徴量ごとの寄与に分ける方法 |
| **コンフォーマル予測** | 過去に外した幅から「外れの何割がこの幅に収まるか」の区間を作る方法 |
| **OOF（アウト・オブ・サンプル）** | 学習に使っていないデータでの成績 |
| **embargo** | 学習と採点の間に挟む空白の期間。未来の覗き見を防ぐ |
| **rank-IC** | 予測の順位と実際のリターンの順位の揃い具合。+1 で完全一致、0 でデタラメ |
| **共通域** | 比べる両方で予測がある会社と月だけにそろえた範囲 |
