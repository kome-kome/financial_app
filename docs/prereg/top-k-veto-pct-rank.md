# 事前登録: 拒否権に使う K を、上位K社の実現順位の平均で測り直す

- 事前登録の Issue: https://github.com/kome-kome/financial_app/issues/1156
- 前の事前登録: `docs/prereg/top-k-veto.md`（#1044・上位K社超過リターン・2026-10-28 の実走で「該当なし」）。方針は ADR-0069。
- 計測道具: `scripts/measure_top_k_veto.py --series pct_rank`（日中枠 `measure:top-k-veto-pct-rank`）。
- **凍結**: この文書は main へのマージで凍結する。凍結値は、マーカー行より上（本文）を改行 LF・UTF-8 にそろえた sha256（`scripts/prereg.py`）。
- 実走は日中キューで単独に回す。

## 1. 問い

#1044 では、上位K社超過リターンのぶれが大きすぎて、どの K でも拒否権（候補が現行より有意に悪化したときだけ昇格を止める・ADR-0069）の規則を満たさなかった。超過リターンは上位 K 社の実現リターンの平均なので、1 社の大勝ち・大負けで大きく動く。

**上位K社の実現順位の平均**（上位 K 社の実現リターンが、その期の全社の中で何番目だったかを 0〜1 で表した値の平均）は外れ値に引っ張られない。この系列に**同じ規則を当てて**、拒否権に使える K があるかを、結果を見る前に固定した規則で決める。変えるのは系列と、その系列の「でたらめな並びのときの値」（中心）だけで、対象・K の候補・閾値は #1044 と同じにする。

## 2. 対象

- モデル: M-1（`macro_risk_return`）・M-2（`macro_gbdt`）・M-6（`macro_enet`）。
- K の候補: 5・10・30。
- 系列: 各モデルの上位K社の実現順位の平均の期別系列（`top_k_pct_rank_by_period`・#1159）。各期の値は、予想の上位 K 社（境目の同点は枠を均等に分ける・`_top_k_shares`）の実現順位の平均。実現順位は、その期の全社の実現リターンの順位（同点は平均順位・`_avg_ranks`）を (順位 − 1) / (社数 − 1) で 0〜1 にしたもの（最下位 0・最上位 1）。
- 並び: 画面の並びの採点（`oof_backtest_display`・#1042）があればその系列、無ければ予想の採点（`oof_backtest`）の系列（#1044 と同じ）。2026-11-06 以降は 3 モデルとも λ=0 なので、予想の採点になる見込み。
- 出どころ: `model_comparison.run_comparison`（モデル比較と同じ手続き。各プラグインの既定パラメータ・walk-forward の fold・embargo は本番のまま）。規則はスキーマ既定の行だけで判定する（本番の設定の行は選択の楽観を含む・#1115）。
- 期: 各モデル自身の OOF の test 期。モデル間の差を取らないので、期をそろえない。

## 3. 量

- 中心: 0.5。期内の全社の実現順位の平均はちょうど 0.5 なので、でたらめな並びの期待値は 0.5。「平均 − 0.5」は超過リターン（上位平均 − 全社平均）と同じ向きの量になる。
- 平均: 期別系列の単純平均。
- SE: 期別系列の平均の定常ブートストラップ SE（`model_stats.bootstrap_mean_se`）。抜き直しの回数・平均ブロック長・乱数の種は `model_stats` の既定（#1044 と同じ）。
- MDE = (z₀.₉₅ + z₀.₈₀) × √2 × SE。片側 α=0.05・検出力 80%。√2 は、拒否権の検定が「候補 − 現行」の対比較で、その差の SE を各モデルの SE の √2 倍と保守側に見積もるため（#1044 と同じ）。

## 4. 判定

- 各モデル・各 K について、MDE ≤ 0.5 × |平均 − 0.5| なら合格。2 期未満で SE が出ない K は不合格。
- **全モデルで合格する最小の K** を、この系列での拒否権の K の候補とする。
- どの K も全モデルでは合格しなければ「該当なし」。上位K社の実現順位の平均は参考のままにする。
- 規則の入力は各モデル自身の系列のぶれだけで、モデル間の差・勝ち負けは見ない。
- 1 モデルでも系列がそろわなければ判定しない（計測道具は終了コード 3 で止まる）。
- **K が決まっても、それだけでは拒否権・同点決めに組み込まない。** ADR-0069 の決定 3 は拒否権の指標を上位K社超過リターンと定めているので、この系列を拒否権（または同点決め・ADR-0070 の追記）に使うかは、結果を見て利用者が判断し、ADR-0069 への追記で決める。

## 5. 手順

1. 日中キューに `measure:top-k-veto-pct-rank` を積む。計測道具は `--prereg` と `--prereg-sha`（追記節の凍結値）を必須にし、本文が凍結値と一致しなければ終了コード 2 で止まる。系列（`pct_rank`）とこの文書の Issue（#1156）が食い違っても終了コード 2 で止まる。
2. 出力（`scripts/.cache/top_k_veto_pct_rank.json`）の表と選ばれた K を、追記節の「結果」に書き写す。
3. K が決まれば、利用者に拒否権・同点決めへ使うかを聞き、使うなら ADR-0069 へ追記し、ゲートへ組み込む Issue を起票する。「該当なし」なら記録して参考のままにする。

## 6. 凍結し直す条件

計測道具を一度も回していない間に限り、本文と凍結値を同じ PR で変えてよい。回した後に対象・K の候補・閾値を変えるなら、新しい ADR で覆す（ADR-0069 の Consequences）。
