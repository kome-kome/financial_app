# 事前登録: 拒否権に使う K（上位何社で測るか）

- 事前登録の Issue: https://github.com/kome-kome/financial_app/issues/1044
- 親: #1040（方針は ADR-0069）。計測道具: `scripts/measure_top_k_veto.py`（日中枠 `measure:top-k-veto`）。
- **凍結**: この文書は main へのマージで凍結する。凍結値は、マーカー行より上（本文）を改行 LF・UTF-8 にそろえた sha256（`scripts/prereg.py`）。
- 実走は日中キューで単独に回す。積むのは人（#1040）。

## 1. 問い

上位K社超過リターンを拒否権（候補が現行より有意に悪化したときだけ昇格を止める・ADR-0069）に使うとき、何社で測るか（K）を決める。K が小さいほど「画面の上位数社を買う」運用に近いが、1 期あたり K 社しか使わないのでぶれが大きく、拒否権が事実上働かない。候補の勝ち負けを見てから K を選ぶと、効いているように見えるだけの規則になる（ADR-0045 / ADR-0050）。そこで、**ぶれだけで K を決める規則を、測る前に固定する**。

## 2. 対象

- モデル: M-1（`macro_risk_return`）・M-2（`macro_gbdt`）・M-6（`macro_enet`）。
- K の候補: 5・10・30。
- 系列: 各モデルの上位K社超過リターンの期別系列（`top_k_excess_return_by_period`・#1041）。上位 K 社の実現リターンの平均から、同じ期の全社の平均を引いた値の、OOF の test 期ごとの並び。
- 並び: 画面の並びの採点（`oof_backtest_display`・#1042）があればその系列、無ければ予想の採点（`oof_backtest`）の系列。画面の既定で λ>0 の M-1 / M-2 は前者、λ=0 の M-6 は後者になる。
- 出どころ: `model_comparison.run_comparison`（モデル比較と同じ手続き。各プラグインの既定パラメータ・walk-forward の fold・embargo は本番のまま）。
- 期: 各モデル自身の OOF の test 期。モデル間の差を取らないので、期をそろえない。

## 3. 量

- 平均: 期別系列の単純平均。
- SE: 期別系列の平均の定常ブートストラップ SE（抜き直した平均の標準偏差・`model_stats.bootstrap_mean_se`）。抜き直しの回数・平均ブロック長・乱数の種は `model_stats` の既定（`bootstrap_mean_ci` と同じ）。
- MDE = (z₀.₉₅ + z₀.₈₀) × √2 × SE。片側 α=0.05・検出力 80%。√2 は、拒否権の検定が「候補 − 現行」の対比較で、その差の SE を各モデルの SE の √2 倍と保守側に見積もるため。

## 4. 判定

- 各モデル・各 K について、MDE ≤ 0.5 × |平均| なら合格。2 期未満で SE が出ない K は不合格。
- **全モデルで合格する最小の K** を拒否権の K とする。
- どの K も全モデルでは合格しなければ「該当なし」。拒否権は導入せず、上位K社の指標は参考のままにする（ADR-0069 にその旨を追記する）。
- 規則の入力は各モデル自身の系列のぶれだけで、モデル間の差・勝ち負けは見ない。
- 1 モデルでも系列がそろわなければ判定しない（計測道具は終了コード 3 で止まる）。

## 5. 手順

1. 日中キューに `measure:top-k-veto` を積む（人）。計測道具は `--prereg` と `--prereg-sha`（追記節の凍結値）を必須にし、本文が凍結値と一致しなければ終了コード 2 で止まる。
2. 出力（`scripts/.cache/top_k_veto.json`）の表と選ばれた K を、追記節の「結果」に書き写す。
3. K が決まれば ADR-0069 を accepted へ更新し、拒否権をゲートへ組み込む Issue を起票する（#1040）。

## 6. 凍結し直す条件

計測道具を一度も回していない間に限り、本文と凍結値を同じ PR で変えてよい。回した後に対象・K の候補・閾値を変えるなら、新しい ADR で覆す（ADR-0069 の Consequences）。
