## 0. 記号

- **週**: ISO 週（月曜始まり）。週次株価 `stock_price_weekly.week_start` と同じ。週次リターン r_{i,w} = log(close_{i,w} / close_{i,w−1})。株価の分割調整は学習ラベルと同じ週次ローダ（`plugins/macro_snapshots.py`）に従い、別のローダを書かない。
- **指数修正日 D_m**: m 回目の係数変更が効く日。**圧力日 P_m**: D_m の前営業日（指数連動資金は P_m の終値で売買する）。**圧力週 w_m**: P_m を含む週。
- **公表の反応週 A\***: 公表後の最初の取引日を含む週。
- **処置群 T**、処置社 i にマッチした対照 **C(i)**（最大 5 社）。
- **異常リターン** AR_{i,w} = r_{i,w} − mean_{j∈C(i)} r_{j,w}（週次 log。52 週ラベルと加法的にそろう）。
- **カレンダー時間の系列** AR̄_w = 週 w に処置社と対照の両方の値がそろう処置社 i で AR_{i,w} を等加重平均した値。
- **CAR[a, b]** = Σ_{w=a}^{b} AR̄_w。窓の端の週番号は、断りが無ければ w_m を 0 とした相対週。
- 有意の判定は「p < 補正後 α」（ADR-0063）。

## 1. 問いと確証の範囲

確証に使う検定は §6 の **E族**（株価のイベントスタディ 4 本）、**M族**（モデルの置き方 4 本）、**2026 群の前向き監視** だけ。それ以外の量はすべて記述（§9）で、採否の根拠にしない。

## 4. 群と対照

### 4.1 処置群

- **2022**: ITT（最初の指定どおり）の 493 社。2023-10 に解除された 43 も含める（解除は結果で選ばれているので、解除後の動きは記述のみ）。
- **2026**: ITT の移行措置 683 社を 8 回とも。2027-10 の再評価で 0.500 停止になった社も外さない（再評価は価格の結果で決まるので、それで群を絞ると結果で選んだことになる）。新規採用 35 は記述のみ（R9）。

### 4.2 対照

- **C1（主）**: data_j の規模区分が '-' で、かつ台帳外の社。2022 の C1 は現時点の data_j でしか作れないので、時点のずれ（後年に区分が変わった社）を数えて記述する。
- **C2（頑健性）**: TOPIX 継続と推定される社。処置群は小型なので、C2 では規模の caliper を満たす相手が少ない見込み。相手の見つかった社数を出し、結論は C1 で読む。

### 4.3 マッチング

- マッチ日（§3.3）の値で、17 業種を完全一致させたうえ、Mahalanobis 距離の k = 5 最近傍を復元ありで取る。
- 変数: logcap、log(直近 52 週の Σturnover ／ 時価総額)、log PBR、直前 52 週の log リターン。
- caliper: 4 変数それぞれで、処置社との差が（処置候補＋対照候補をプールした）標準偏差の 0.25 倍を超える相手は使わない。
- 5 社そろわない処置社は、そろった社数で平均する。1 社も無い処置社は外し、外した数を群別に出す。
- バランス: 主の仕様（C1・主のマッチ日）で 4 変数すべて SMD < 0.1。満たさなければ R0 を不成立とする（マッチの仕様も caliper も、結果を見て動かさない）。

### 5.2 推論の部品

- **Newey-West の分散**: 窓の重み c_w を AR̄_w に掛けた線形結合 Σ c_w AR̄_w の分散を c'Ωc とし、Ω は解析期間の AR̄ 系列から Bartlett 核・lag 4 で推定する。H0 の平均 0 の下で、平均を引かずに自己共分散を取る。解析期間は 2022 前例で [A\* − 26, w_10 + 52]、2026 群で [A\* − 26, その時点の最新週]。
- **残差の定常ブートストラップ**（κ・δ̂・ρ の CI と E2 の p）: AR̄_w をその週の窓の種類ごとの平均（圧力窓・戻り窓・除外後の窓・それ以外＝0）とその残差に分け、残差を平均ブロック長 8 週の定常ブートストラップ（`model_stats` の Politis-Romano と同じ手続き）で解析期間の長さに引き直し、平均へ戻して量を計算し直す。B = 2,000、seed = 0。CI はパーセンタイル。
- **placebo**: 同じ処置・対照の組で、2014-01〜2018-10 の 1・4・7・10 月の最終営業日の前営業日を含む週（最大 20 個）を擬似の圧力週とし、擬似の圧力窓 CAR を作る。そこから 10 個を非復元で引いた平均を 10,000 回（seed = 0）作り、E1 の経験 p と誤検出率（その平均に E1 と同じ Newey-West の片側 5% 検定を当てて棄却した割合）を出す。E4 の経験 p は、同じ期間の各四半期末から始まる擬似の 52 週窓の CAR の分布で出す。週次株価が無い四半期は使わず、使えた数を記録する。15 個未満なら経験 p も誤検出率も出さない（切り替えも起きない）。
- **経験 p への切り替え**: stage A の placebo 誤検出率が名目 5% ± 5pt（0〜10%）を外れたら、E1 と E4 の確証の p を placebo の経験 p に切り替える。

### 5.3 first stage（暦の検査）

各圧力週 w_m について、処置社の log(その週の売買代金 ／ 直前 26 週の売買代金の中央値) から、対照で同じ量の平均を引いた値を作り、処置社間の t 値を取る。全ての m で t ≥ 3 でなければ、暦の誤りとして計測を止める（R0）。

## 6. 確証の検定

### 6.1 E族（2022 前例・すべて片側・Holm で全体 α = 0.05）

量の定義（m = 1..10）:

- I = (1/10) Σ_m CAR[w_m − 1, w_m]（1 回あたりの圧力）
- R = (1/10) Σ_m CAR[w_m + 1, w_m + 4]（その直後 4 週の戻り。戻れば正）
- κ = 1 + R / I（持続率。1 なら全く戻らない、0 なら全部戻る）
- **δ̂（52 週換算）** = 4 × (I + R)（年 4 回の低減が、戻らずに残る分の合計。ラベルと同じ log リターンの単位）。CI は 90%（R2・R4・R5 が使う）を残差ブートストラップで出す。
- CAR_post = CAR[w_10 + 1, w_10 + 52]

| 検定 | H1 | p の出し方 |
|---|---|---|
| E1 平均インパクト | I < 0 | Newey-West（§5.2）による片側 p。§5.2 の切り替え条件で経験 p |
| E2 持続率 | κ > 0 | 残差ブートストラップで κ\* ≤ 0（I\* ≥ 0 の回も含む）となった割合 (n + 1)/(B + 1)。I ≥ 0 なら非有意とする |
| E3 ラベル水準の DiD | b < 0 | 下記の回帰の b の Newey-West（lag 12 か月）片側 p |
| E4 除外後の戻り | CAR_post > 0 | Newey-West（§5.2）による片側 p。§5.2 の切り替え条件で経験 p |

- **E3**: 本番の学習ラベル（月末 ym から 52 週先の log リターン）y について、D_ym = mean_{i∈T}[ y_{i,ym} − mean_{j∈C(i)} y_{j,ym} ] を作り、D_ym = a + b·1[ym ∈ 事象期] を最小二乗で当てる。事象期 = 2022-10〜2024-01 の月末（窓が低減期間に収まる 16 期）、基準期 = 2016-01〜2017-12 の月末（市場構造の見直しの議論が公になる前の 2018 年中に窓が終わる 24 期）。2018-01〜2022-09 の月末は使わない。
- **Holm**: 4 本の p を小さい順に p_(1) ≤ … ≤ p_(4) と並べ、p_(j) < 0.05 / (5 − j) が成り立つ間だけ順に有意とし、初めて成り立たない所で止める。

### 6.2 M族（2022 前例・両側・Bonferroni で各 α = 0.0125）

- 本番の構成でそろえる（ADR-0041 / ADR-0047）: M-2 は raw、M-6 は size_neutral の OOF。
- 群ラベルは t22:treated / t22:control（§4 のマッチ対）。期ごとに対の両方がそろう行だけを使う（ADR-0045）。
- 期 t の placement bias（`scripts/momentum_gate.py` の `blank_group_breakdown` と同じ定義＝予測の順位分位 − 実現の順位分位の群平均）から d_t = bias_T(t) − bias_C(t) を作る。
- d_t = a + b·E_t + c·P_t を最小二乗で当てる。E_t = その期のラベル窓に入る低減の回数 ／ 4、P_t = ラベル窓のうち除外（2025-01-31）より後の割合。2021 年の期は先回りが混じるので回帰に入れず、記述する。
- 検定は {M-2, M-6} × {b, c} の 4 本。**確証の p は順列検定**: 規模十分位 × 流動性三分位 × 17 業種の層ごとに、処置群と同じ社数を処置群・対照以外の社から引いた擬似処置群を作り、全期で固定したまま（系列相関を保つ）d\*_t = bias_{擬似}(t) − bias_C(t) で同じ回帰を当てる。1,000 回（seed = 0）で p = (#{|b\*| ≥ |b|} + 1) / 1,001（c も同様）。Newey-West（lag 3）の p は併記するが判定には使わない。
- 向きはモデルで逆になりうる（M-2/M-6 は割安化で上へ、M-3 は年率化で下へ）ので両側。

### 6.3 前向き監視（2026 群・片側・O'Brien-Fleming 型 α 消費で全体 α = 0.05）

- 各低減 m の圧力週の 2 週後（w_m + 2 の週の終値がそろった時点）に k = m 回目の検定を行う。
- 統計量: Z_k = Σ_{j≤k} CAR_j[w_j − 1, w_j] ÷ その標準誤差（§5.2 の Newey-West、lag 4）。**Z_k ≤ −z_k なら棄却**（負の価格効果を確証）。
- 情報割合は計画どおり t_k = k/8 に固定し、実施が遅れても計算し直さない。

## 7. 閾値と δ*

- ΔIC 0.005、placement 0.03。
- **δ\***（#1010）: OOF で G26（2026 移行措置の社の過去行）と G22 のラベルに y' = y + δ·x（x = ラベル窓内の予定低減割合）を当て、δ ∈ {−1, −2, −3, −5, −8, −10%} を順に試す。δ\* = ΔIC ≤ −0.005 または |placement| ≥ 0.03 となる最小の |δ|。モデル（M-2・M-6）ごとに出し、R2〜R5 はそのモデルの δ\* で判定する。どの δ でも満たさなければ δ\* = 0.10 とみなす。
- **MDE**（stage A・盲検）: 2022 前例の処置・対照の組で、事象の前の 2014-01〜2018-12 の AR̄ 系列から §5.2 と同じ Newey-West（lag 4）で Ω を推定し、δ̂ = 4 × (I + R) の重み c で SE(δ̂) = √(c'Ωc) とする。MDE = (z_{0.95} + z_{0.80}) × SE(δ̂)（片側 5%・検出力 80%）。事象窓の値は使わない。
