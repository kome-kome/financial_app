## 0. この資料の歩き方

M-3 がやりたいことを一言でいうと、次の通りです。

> **「銘柄ごとに、株価が為替・金利・株価指数・商品などの動きにどれだけ反応するか（β）と、
> それでは説明できない持続的な上乗せ（α）を、毎週少しずつ更新しながら推定する。
> 最新の α を 1 年分に直したものを、その銘柄の期待リターンとする」**

M-1・M-2 が「ある時点で、多くの会社を横に並べて 1 組の係数を推定する」のに対し、M-3 は
**係数そのものが時間とともに変わる**と考え、1 社ずつその変化を追いかけます。

| 章 | 問い | キーワード |
|---|---|---|
| 1 | そもそも何を作りたいの？ | M-1・M-2 との違い |
| 2 | 「係数が時間とともに変わる」とは？ | **時変係数** |
| 3 | 何を観測するの？ | 週次リターン・マクロの週次変化・**α と β** |
| 4 | どうやって推定するの？ | **ベイズ更新・カルマンフィルタ・割引係数** |
| 5 | 期待リターンはどう作るの？ | μ̂ = 最新の α・注意点 |
| 6 | 本当に当たっているの？ | 自己診断・ファクターの採否・答え合わせ |
| 7 | 用語集・参考文献 | ― |

## 1. そもそも何を作りたいのか

### 1-1. M-1・M-2 との違い

| | M-1（直線）・M-2（木） | M-3（状態空間） |
|---|---|---|
| 見方 | ある月に、**多くの会社を横に並べて**比べる（横断） | **1 社の株価の歴史を縦に**追う（時系列） |
| 係数 | 推定する時点では 1 組（**静的**） | 毎週変わってよい（**時変**） |
| 材料 | 財務の比率＋マクロ（年単位の変化） | 週次の株価リターン＋マクロの**週次**の変化 |
| 予測する対象 | 52 週先のリターン | 来週のリターン（の積み重ね） |
| 自信の表し方 | 予測のぶれ幅を別に計算 | 推定値そのものに**信用区間**が付く |

つまり M-3 は、財務の比率を使わず、「**この会社の株価は、マクロの動きにどう反応してきたか、その反応は今どう変わりつつあるか**」を
株価の歴史から読み取るモデルです。M-1・M-2 とは材料も見方も違うので、同じ会社を別の角度から評価することになります。

### 1-2. 最終アウトプット

- **期待リターン μ̂ のランキング**（信用区間つき）
- **β の推移のグラフ**：「この会社の円安への感応度は、この 2 年でどう変わったか」を区間つきで見られる
- **自己診断**：予測の外れ方が妥当か（第6章）

## 2. 「係数が時間とともに変わる」とは

### 2-1. 例：円安への感応度が年々小さくなる会社

ある輸出企業を考えます。昔は円安になるたびに株価が大きく上がっていました（円安への感応度＝β が大きい）。
ところがこの会社は、海外の工場を少しずつ増やし、海外で作って海外で売る割合を高めてきました。
すると、円安の恩恵はだんだん小さくなり、**β も年々小さくなっていきます**。

```
 円安への感応度 β
  大 │●●●
     │    ●●●
     │        ●●●●
     │             ●●●●●
  小 │                   ●●●●   ← 今
     └──────────────────────────→ 時間
```

### 2-2. 全期間で 1 本の直線を引くと何が困るか

ふつうの回帰で全期間をまとめて推定すると、上の図の**平均**のような値が 1 つ出るだけです。
今の感応度は平均より小さいのに、その変化は見えません。

かといって、直近の数週だけで推定すると、データが少なすぎて**雑音に振り回されます**。
M-3 は、この 2 つの間をとる方法を使います。**過去のデータを少しずつ忘れながら、毎週の新しいデータで推定を更新する**のです（第4章）。

## 3. 観測のしかた ― 週次リターンとマクロの週次変化

### 3-1. 同じ週の動きどうしを並べる

M-3 は毎週、次の 2 つを並べます。

- **その週の株価リターン**（先週の終値から今週の終値への変化率）
- **その週のマクロの変化**（ドル円・米金利・株価指数・原油・銅などが、その週にどれだけ動いたか）

株価指数・為替・商品は**変化率（対数リターン）**で、金利やニュースの論調のように**正負をまたぐ系列は差**で測ります
（マイナスの値がある系列は、割り算の変化率が定義できないため）。

これは「**同じ週にマクロがこう動いたとき、この株はどれだけ一緒に動いたか**」を測る見方で、
金融の理論では APT（裁定価格理論・Ross 1976）の考え方に沿っています。

### 3-2. α と β

1 週分の関係を式にすると、次の形です。

```
 今週の株価リターン ＝ α ＋ β₁×（ドル円の変化）＋ β₂×（米金利の変化）＋ … ＋ 雑音
```

- **β（ベータ）**：それぞれのマクロの動きへの**感応度**。「ドル円が 1% 動くと、この株は何 % 動くか」
- **α（アルファ）**：マクロの動きでは説明できない、その会社**固有の持続的な上乗せ**
- **雑音**：どちらでも説明できない、その週だけの偶然の動き

株価指数（日経平均・TOPIX）をマクロに含めると、α は「市場全体とマクロの動きを差し引いた後に残る、その会社だけの強さ」になります。

### 3-3. 週次の系列だけを使う理由

マクロの統計には、月に 1 回や年に 1 回しか発表されないもの（物価・景況感など）もあります。これを週の表に入れると、
発表のない週は同じ値で埋まり、**週の変化がほとんどゼロ**になります。変化を観測するモデルにとっては、情報がほぼ無い列です。
そのため M-3 は、毎日（毎週）値が動く系列だけを使い、月次以下の系列は M-1・M-2 に任せています
（[ADR-0012](adr/0012-m3-dlm-weekly-only-factors.md)）。日本の 10 年金利も、月次の統計から財務省の日次データへ差し替えました
（[ADR-0029](adr/0029-m3-jp10y-daily-mof-source.md)）。

使えるマクロ系列の全リストと既定の選択の正本は `plugins/macro_dlm.py` の `_DLM_MACRO_MAP` と [MODELS.md §12.2](MODELS.md) です。

### 3-4. 価格の動きの特徴量（1 週遅れ）

マクロとは別に、その株自身の値動きの荒さ・出来高の急増・52 週高値からの距離・直近 4 週の反動といった特徴量を足せます。
これらは**前の週までに分かっている値**を使います（同じ週の値を使うと答えを覗くことになるため）。
マクロの列（同じ週の動きへの反応）とは意味が違うので、結果も別の枠で報告します。

## 4. ベイズ更新 ― 毎週「見込み」と「答え」を突き合わせる

### 4-1. 見えないものを、見えるものから推し量る

α と β は直接は見えません。見えるのは毎週の株価リターンとマクロの動きだけです。
このように「**見えない状態**（α・β）が少しずつ変わり、**見える観測**（株価）はその状態と雑音から生まれる」と考えるモデルを
**状態空間モデル**と呼びます。M-3 はその中でも、関係が足し算で書ける**動的線形モデル（DLM）**を使います（West & Harrison 1997）。

### 4-2. 1 週間の流れ

毎週、次の 4 つの手順を繰り返します。カルマンフィルタ（Kalman 1960）と呼ばれる考え方です。

```
 ①ぼかす   先週の推定（α・β とその自信）を、少しだけ自信を減らして今週の出発点にする
     ↓      ＝「先週から少しは変わっているかもしれない」
 ②予想する 今週のマクロの動きを使って、今週の株価リターンを予想する（観測の前に）
     ↓
 ③答え合わせ 実際のリターンを見て、予想とのずれ（誤差）を測る
     ↓
 ④動かす   ずれた分だけ α・β の推定を動かす。自信が無い係数ほど大きく動く
```

④で「どれだけ動かすか」は、**今の推定にどれだけ自信があるか**と、**観測がどれだけ雑音まじりか**の釣り合いで自動的に決まります。
推定に自信が無ければ新しい観測を重く見て大きく動かし、観測の雑音が大きければ慎重に少しだけ動かします。

> **天気予報のたとえ**：前日の予報（①②）を出し、実際の天気（③）を見て、外れ方に応じて次の予報のくせを直す（④）。
> 1 回の外れで大きく変えすぎず、外れが続けば着実に直していく——この加減を数式で決めているのが ④ です。

### 4-3. 割引係数 ― どれだけ早く忘れるか

①の「少しだけ自信を減らす」量を決めるのが**割引係数 δ（デルタ）**です。

| δ | 意味 | 向いている状況 |
|---|---|---|
| 1 に近い | 過去をなかなか忘れない。係数はゆっくりしか動かない | 感応度が安定している会社。雑音に強い |
| 小さめ | 過去を早く忘れる。係数が速く動いてよい | 事業の中身が変わりつつある会社。ただし雑音にも振り回されやすい |

δ を陽に決めておけば、状態がどれだけ揺れるかを会社ごとに難しい計算で求める必要がなく、1 社 1 回の計算で済みます。
観測の雑音の大きさ（分散）も同じように少しずつ忘れながら学び、その忘れ方を決める係数（β_v）もあります。

δ と β_v の値は、第6章の答え合わせ（OOF の rank-IC）で良かったものを探索で選んでいます
（候補の正本は `plugins/macro_dlm.py` の `MacroDlmPlugin.tuning_search_space`）。

### 4-4. 信用区間 ― 推定値に自信の幅が付く

ベイズ更新では、推定値は「1 つの数」ではなく「**どのあたりにありそうかの分布**」として持ち続けます。
そのため α・β には毎週、「95% の確からしさでこの範囲にある」という**信用区間**が付きます。β の推移のグラフで帯のように見えるのがそれです。
予測の分布には、まれな大きな外れに備えて、正規分布より裾の厚い **Student-t 分布**を使います。

## 5. 期待リターン μ̂ の作り方と注意

### 5-1. μ̂ ＝ 最新の α を 1 年分に

M-3 の期待リターンは、**最後の週の α を 1 年分（52 週分）に直したもの**です。

なぜ β は使わないのでしょうか。β は「マクロが動いたら、この株はどれだけ動くか」という**反応の強さ**で、
**来年マクロがどう動くかは誰にも分からない**からです。将来のマクロの動きが分からない以上、予測に残るのは
マクロとは関係のない持続的な上乗せ、つまり α だけ、という考え方です。

> α を「今の水準がそのまま続く」と見る（ランダムウォーク）のが基本ですが、「時間とともに 0 へ戻っていく」と見る
> 選択肢（AR(1)）もあり、探索の候補に入っています。後者は今の α を割り引いた控えめな予測になります。

### 5-2. 1 社ずつ推定するので、歴史の短い会社は対象外

M-3 は 1 社の歴史だけで推定するので、十分な週数が無い会社（既定では約 2 年未満）は対象になりません。
株価やマクロが欠けている週は飛ばし、残りを続けて観測したものとして扱います。

### 5-3. 歴史の浅いマクロ系列は自動で外す

M-3 は、毎週**全部のマクロの値がそろっている**必要があります（M-2 のように欠けを残したまま学習できません）。
歴史の浅い系列を選ぶと、その系列が無い週がすべて使えなくなり、多くの会社が一度に脱落します。
そこで、週の表で値がそろっている割合が一定（既定 50%）に満たない系列は、自動でモデルから外し、その旨を診断に表示します。

### 5-4. マクロ起因のリスク R_macro ― 時点の再現に注意

β と、マクロの動きの大きさ・連動の仕方から、「**マクロの動きによってこの株がどれだけ揺れるか**」というリスク（R_macro）も計算できます。
ただし過去の成績を測るときには、**最後の週の β を過去の全期間に当てて**計算しています。過去のある時点では、その後の β は分かっていなかったので、
これは**未来の情報を含んだ上限**として扱います（[MODELS.md §11.7.3](MODELS.md)）。

## 6. 本当に当たっているのか ― 答え合わせ

### 6-1. 自己診断 ― 予測の外れ方は妥当か

M-3 は毎週、**観測の前に**来週のリターンを予想しています（第4章の②）。だから、外れ方そのものを点検できます。

| 診断 | 何を見るか | 理想 |
|---|---|---|
| **校正** | 外れの大きさを、モデルが「このくらい外れるだろう」と見込んだ幅で割り、2 乗して平均したもの | 1（見込みどおりの外れ方） |
| **予測の誤差（RMSE）** | 週次リターンの予想がどれだけ外れたか | 小さいほど良い |
| **95% 区間の的中率** | 実際のリターンが 95% の予測区間に入った割合 | 約 95% |

校正が 1 より大きければ「自信を持ちすぎ（外れを小さく見込みすぎ）」、小さければ「慎重すぎ」です。
これは M-1・M-2 の答え合わせとは別の、状態空間モデルならではの自己点検です。

### 6-2. 順位の答え合わせ（OOF）

M-3 も、M-1・M-2 と同じく「予測の順位が実際のリターンの順位とどれだけ揃うか（rank-IC）」で採点し、モデル比較の画面に並びます。
M-3 の予想は**来週 1 週分**で、毎週その週のデータを見る前に作るので、M-1・M-2 のような空白の期間（embargo）を挟まなくても
未来を覗くことが構造的に起きません（[ADR-0014](adr/0014-purge-embargo-walk-forward.md)）。

### 6-3. ファクターを足すかどうかは、測って決める

「このマクロ系列は効きそうだ」と思っても、足すかどうかは実際に測って決めます。その系列を外した版と比べ（leave-out）、
共通の範囲で rank-IC と売り側の指標が有意に良くならなければ、既定には入れません。

- **ニュースの論調・関心度の系列**：選択肢には足しましたが、2 つの指標とも有意な差が出なかったので既定には入れていません
  （`_GATE_REJECTED_FEATURES`・[ADR-0024](adr/0024-news-tone-attention-macro-channel.md)）
- **日本の 10 年金利**：月次の統計のときは、週の変化がほぼゼロで「ほとんど何もしない列」でした。日次のデータへ差し替えたら初めて実質的に効くようになり、
  **その効きが負**だと分かったので、既定から外しました（選択肢には残っています・[ADR-0029](adr/0029-m3-jp10y-daily-mof-source.md)）

> **教訓**：「何もしない列」は害も無いように見えますが、それは効いていないからです。データの質を上げて初めて、
> 本当の効き（良くも悪くも）が見えることがあります。採否は思い込みではなく測定で決めます。

### 6-4. 割引係数の選び方

割引係数（δ・β_v）は、以前は「学習データへの当てはまりの良さ（周辺尤度）」で画面の中で自動に選ぶ機能がありました。
しかし、当てはまりの良さは**まだ見せていないデータでの成績（OOF の rank-IC）とは別の物差し**です。そのうえ、既定値はすでに
OOF の rank-IC で選んだものだったので、自動選択は上書きして悪くする危険のほうが大きく、撤去しました
（[ADR-0007](adr/0007-hyperparameter-tuning-shared-engine.md)）。

### 6-5. 売り候補のランキングで使える

売り候補のランキングは、どのモデルの μ̂ を使うかを選べます。M-3 はその選択肢の一つです（今の既定は M-6。
売りの見分けの力は買いの強さとは別の指標で選んでいます・[ADR-0022](adr/0022-short-side-oof-metric-and-default-mu-source.md)）。

## 7. 用語集

| 用語 | やさしい説明 |
|---|---|
| **時変係数** | 時間とともに変わってよい係数。「感応度が年々変わる」を表せる |
| **状態空間モデル** | 見えない状態（α・β）が少しずつ変わり、見える観測（株価）がそこから生まれると考えるモデル |
| **動的線形モデル（DLM）** | 状態空間モデルのうち、関係が足し算で書けるもの |
| **カルマンフィルタ** | 「ぼかす → 予想する → 答え合わせ → 動かす」を毎回繰り返して、見えない状態を推し量る方法 |
| **ベイズ更新** | 今の見込み（分布）を、新しいデータを見て少しずつ書き換えること |
| **α（アルファ）** | マクロの動きでは説明できない、その会社固有の持続的な上乗せ |
| **β（ベータ）／感応度** | マクロが動いたときに、その株がどれだけ一緒に動くか |
| **割引係数 δ** | 過去の推定をどれだけ早く忘れるか。1 に近いほどゆっくり、小さいほど速く係数が動く |
| **信用区間** | 推定値が「この範囲にありそう」という幅。ベイズ推定では自然に付く |
| **Student-t 分布** | 正規分布より裾が厚く、まれな大きな外れを見込んだ分布 |
| **対数リターン** | 価格の比の対数で測った変化率。週の変化を足し合わせられる |
| **APT（裁定価格理論）** | 株のリターンを、いくつかの経済全体の要因への反応の和で説明する理論 |
| **校正** | 外れ方が、モデルの見込みどおりかどうか。1 が理想 |
| **leave-out** | ある要素を外した版と比べて、その要素の効きを測るやり方 |
| **OOF（アウト・オブ・サンプル）** | 学習に使っていないデータでの成績 |
