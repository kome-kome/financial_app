# 上場廃止した社の行は、本番予測の答え合わせの主審にだけ足す（OOF の比較と学習は今の答えのまま）

## Status

**accepted（2026-11-13）**。#1195（ユーザー判断）。[ADR-0074](0074-delisting-share-is-judged-on-covered-years.md) が「#1195 で決める」とした、
消えた行を採点（と学習）に足すか・2019〜2023 年の読み方・どの比較から適用するかの決定。

## Context

#1197 の計測（事前登録 [`docs/prereg/delisting-redesign.md`](../prereg/delisting-redesign.md)・2026-11-13 の日中枠・exit=0）で、M-4 の共通域の
M-2・M-6 の OOF に、途中で上場廃止した行（特徴量はそろうのに 52 週先の株価が無い行・324 行・2024 年 21 行・2025 年 303 行）を
各 fold の学習済みモデルで予測して足し、最後の終値で手仕舞った答えで採点し直した。判定は **propose_include**。

| 主審（M-6 − M-2・19 期） | 答えのある行だけ | 消えた行を足した |
|---|---|---|
| (a) rank-IC | +0.0436（p=0.099・有意でない） | +0.0442（p=0.092・有意でない） |
| (b) 全社の売り側spread | +0.0161（p=0.032・有意でない） | +0.0167（p=0.016・正に有意） |
| 副: 上位10社超過の差 | +0.0903 | +0.0724 |

入れ替わりは (b) の p が境目 0.025（Bonferroni）をまたいだだけで、差の大きさと向き（M-6 の優位）はほとんど変わらない。
#1154 の配当と同じ形で、そのときは切り替えなかった（[ADR-0073](0073-labels-stay-price-only.md)）。

一方、上位10社超過の**値そのもの**は両モデルとも下がる（19 期で M-6 +0.2131 → +0.1665、M-2 +0.1228 → +0.0941）。倒産の疑いの
6 行を −99% にするとさらに下がる（+0.1303 / +0.0700）ので、倒産の疑いの行の一部は両モデルの上位10社に入っていた。

足す費用は比較ごとに違う。

- **OOF の比較**（`oof_backtest`・#1155 の `scripts/measure_selection_optimism.py` など）: 消えた行は学習パネルに居ないので、
  各 fold の学習済みモデルで予測し直す仕組みが比較ごとに要る。しかも 2019〜2023 年は廃止社がパネルに居ない（ADR-0074）ので、
  19 期のうち 12 期は足しても変わらない
- **本番予測の答え合わせ**（#1157・`scripts/measure_live_oos.py`）: 月次の写し（`prediction_snapshots`）には、のちに廃止した社の
  予測も残る。道具は既に「足した版」を参考として計算しており、主審と入れ替えるだけで済む。初回の採点（2027-01-25 以降）より前なら、
  事前登録 [`docs/prereg/live-oos.md`](../prereg/live-oos.md) §6 のとおり本文と凍結値を変えられる

## Considered Options

1. **本番予測の答え合わせ（#1157）の主審にだけ足す。OOF の比較と学習は今のまま**——採用
2. **#1155 の計測と #1157 の両方に足す**——却下。12/4 以降の計測までに、選び直した M-2 と M-6 の各 fold のモデルで消えた行を
   予測する仕組みを計測道具へ組み込む費用に対し、判定の向きは変わらない
3. **どこにも足さない（配当と同じ扱い）**——却下。本番予測の答え合わせは運用の実態（保有株が TOB や倒産で上場廃止すれば、
   その価格で手仕舞う）を測るためのもので、足す費用もほぼ無い
4. **学習にも足す**——却下。2019〜2023 年は廃止社が居ないので、学習に足すと 2024 年以降だけ答えの作り方が変わる。
   `PREPROCESS_VERSION` を上げ、探索の周回をやり直す費用もかかる

## Decision

1. **OOF の比較（#1155 を含む）は、今の答え（52 週先の終値がある行だけ）のまま採点する**
2. **本番予測の答え合わせ（#1157）の主審は、上場廃止した社を最後の正の終値で手仕舞った答えで足した版にする**。
   差し替えは #1210（2027-01-25 の中間点検より前）。倒産の疑いを −99% にする版は足さない
3. **学習の答えは変えない**。`PREPROCESS_VERSION` も上げない
4. 2019〜2023 年の test 月は、生き残った社だけを採点していると読む（ADR-0074 のまま・注記だけ）

## Consequences

- OOF の上位10社超過の**値そのもの**は、廃止した社（多くは TOB の当たり・一部は倒産）が入らないぶん高めに出る。2026-11-13 の
  計測では、足すと 19 期で M-6 が +0.2131 → +0.1665、M-2 が +0.1228 → +0.0941、2024 年以降の 7 期だけでは M-6 が
  +0.2443 → +0.1177、M-2 が +0.3139 → +0.2357。モデルの間の差の向きは変わらない。OOF の予測を使う運用再現
  （`scripts/oof_portfolio_replay.py`）も、廃止の前の社を選べないので同じ向きにずれうる（GOTCHAS.md「分析・計算の実装メモ」）
- 本番予測の答え合わせ（#1210 の後）と OOF の比較は、答えの規則が違う（前者は廃止した社を含む）。両者の上位10社超過を
  そのまま並べて比べない
- 戻すとき: #1210 のマージ前なら #1210 を閉じるだけ。#1157 の初回の採点の後に戻すなら、事前登録 §6 のとおり新しい ADR で覆す
