# 構造的 NULL は業種単位で外し、無配は 0 として扱う（AND フィルタの巻き添えを止める）

## Status

accepted（2026-08-03）。Issue #434。

## Context

夜間バッチ（#432）で `gap_ratio` の陳腐化は解消したが、**そもそも `gap_ratio` が付いている
企業が母集団の 74.4%（2,882 / 3,874社）しかない**ことが実測で判明した。

`_classify_by_sector` は AND フィルタ（選択列が1つでも NULL の企業を丸ごと除外）である。
既存の防御 `_select_features` は **母集団全体**の欠損率が 50% 超の列しか外さないため、
以下2種類の *構造的な NULL*（＝「未収集」ではなく「会計上そもそも存在しない」）が
そのまま AND に効き、企業や業種を丸ごと分析対象外にしていた。

| 構造的 NULL | 全体欠損率 | 業種内欠損率 | 影響 |
|---|---|---|---|
| 銀行業の `ps_revenue` / `ps_gross_profit` / `ps_operating_profit` | 3.8% / 7.7% / 1.4% | **100%** | 銀行業 79社が全滅 |
| 証券・保険・陸運・倉庫・電気ガス・その他金融の `ps_gross_profit` | 同上 | 41〜76% | 業種の大半が脱落 |
| 無配企業の `dps` | 17.1% | 医薬品 53% / 情報通信 38% / サービス 26% | 662社が脱落 |

2点目が特に悪い。XBRL は配当が無い場合そもそもタグを出さないため、**無配（真の 0）と
未収集が同じ NULL に潰れる**。欠落はランダムではなく**無配＝再投資型／赤字企業に偏る系統的
バイアス**で、そうした企業が丸ごとバリュエーション分析の対象外になっていた。

`min_coverage`（既定 0.5）にも引っかからないため、この 25.6% の欠落は画面から見えない。

## Considered Options

1. **`MAX_FEATURE_MISSING_RATE` を下げる**（例 0.15）: `dps` が自動ドロップされ 790社が救われるが、
   **全社で配当情報を失う**。銀行業の売上総利益（全体 7.7%）は救えない。
2. **必須列／任意列を分け、任意列は業種中央値で補完**: 補完値は観測ではないので、`dps` の
   「無配」を業種中央値の配当で埋めると意味が反転する。
3. **業種単位で列を外す＋無配は 0 埋め**（採用）。
4. **欠落の可視化のみ**: 見えるようにはなるが 25.6% は欠落したまま。

## Decision

**構造的 NULL は「欠測」ではなく「該当なし」として、欠測とは別に扱う。**

- **業種単位のドロップ**（`_sector_feature_sets`・パラメータ `sector_missing_rate`・既定 **0.3**）:
  業種内欠損率が閾値超の列を、**その業種の回帰からのみ**外す。業種別に別の β を推定する
  本モデルでは採用列も業種別で構造的に整合する（業種横断で同じ列である必要はない）。
  `min_samples` に届かない業種を救う貪欲ドロップは業種内へ移設して残す。
- **無配の 0 埋め**（`ZERO_FILL_FEATURES = {"dps"}`・パラメータ `zero_fill_no_dividend`・既定 **ON**）:
  `dps` の NULL を 0 [円/株] として回帰へ入れる。情報を捨てるのではなく、**無配という事実を
  観測値として加える**（案1 が案3 に勝る理由）。
  - 根拠: `dps` NULL 662社を同一年度の FY 開示（`statement_disclosure.div_ann`）と突合すると
    実績配当 0 が 413社・**実績配当 > 0 なのに NULL は 1社（0.2%）**・同年度 FY 行なし 174社・
    `div_ann` 自体が NULL 74社。年度不問（FY 実績の最大値）でも 0 が 599社に対し > 0 は 36社。
  - 開示突合をゲートにする案は採らない。救えるのは 413社に留まり（開示行が無い249社を落とす）、
    防げる誤 0 埋めは 1社なので、プラグインへ開示テーブルの JOIN を持ち込む対価に見合わない。
- 両者は独立したパラメータで、片方ずつ切り戻せる。実測は `scripts/measure_sector_coverage.py`
  （`_persist_and_rank` を差し替えて本番 `regression_results` へ書かずに比較する）。

### 実測（2026-08-03・本番 Supabase・最新年度・OLS・既定10特徴量）

| 設定 | 社数 | R²中央 | 調整R²中央 | n<2p 業種 | 共通社 R² |
|---|---|---|---|---|---|
| 現行相当（両案 OFF） | 2,882 | 0.8788 | 0.7729 | 12 | 0.6014 |
| 案1のみ（`dps` 0埋め） | 3,469 (+587) | 0.8318 | 0.7151 | 11 | 0.5823 |
| 案2のみ（業種内 30%） | 3,273 (+391) | 0.8409 | 0.7248 | 7 | 0.5896 |
| **併用 30%（新既定）** | **3,619 (+737)** | 0.8164 | 0.7151 | **7** | 0.5810 |
| 併用 20% | 3,639 (+757) | 0.8087 | 0.7151 | 7 | 0.5808 |
| 併用 50% | 3,594 (+712) | 0.8164 | 0.7151 | 8 | 0.5813 |

閾値は 20% と 30% で差が 20社・共通社 R² で 0.0002 しかないため、保守側の **0.3** を既定にする。

## Consequences

- カバレッジ 74.4% → **93.4%**（2,882 → 3,619社）。欠落の系統的バイアス（無配企業への偏り）が解消。
- 過学習ゾーン（サンプル数 < 2×パラメータ数）の業種が **12 → 7** に減る。
- **R² の低下は劣化ではない**。母集団が変われば R² は比較不能なので、同一分母（両設定でスコアが
  付く 2,879社）で測ると 0.6014 → 0.5810（−0.020）に留まる。全体 R² が下がって見えるのは、
  従来が「全10列が揃う優等生サブセット」だけを回帰していた**選択バイアスの解消**による。
  典型例が証券・商品先物取引業で、n=6・パラメータ11（自由度ほぼ 0）の R²=1.0000 が
  n=31 で R²=0.8515 になった。前者は当てはまりではなく過学習の表示だった。
  ADR-0025 の「M-1 rank-IC 0.198→0.113 は劣化でなく honest 化」と同型。
- **業種によって説明変数の集合が異なる**。同じ `gap_ratio` でも「何を織り込んだ理論株価との
  乖離か」が業種で変わるため、業種別 R² サマリーに除外列の列を追加して画面に出す。
- 0 埋めの適用範囲は `ZERO_FILL_FEATURES` に限定する。「NULL は 0」を全列に広げると
  未収集を 0 と偽ることになり、逆向きのバイアスを作る。
