# 保有の組み方は今のまま——2 モデルの上位の合算を等金額で持ち、業種・銘柄の上限は置かない

## Status

**accepted（2026-11-19）**。#1227。事前登録 [`docs/prereg/portfolio-construction.md`](../prereg/portfolio-construction.md)
§4 の機械的な判定（C＝今のまま）に従う。判定に従わずに覆すときは、新しい ADR で理由を添える（同 §4）。

## Context

実運用は「M-6 と M-2 の画面上位から約 10 社ずつ買い、保有の下位 1/5 を売る」（[ADR-0070](0070-search-selects-in-two-stages-for-top-k-buying.md)）。
2 本の一覧の合わせ方、1 業種に持つ数の上限、1 銘柄に配る金額は決まっていなかった。

事前登録した構成を、OOF 運用再現（売りの並びは本番と同じ S2・[ADR-0076](0076-sell-ranking-orders-by-the-sell-quantile-model.md)、
同点は [ADR-0077](0077-replay-ties-break-by-hash.md)）で開始月をずらした 3 経路回した（2026-11-19・95.5 分・exit 0）。

| 構成 | TOPIX に対する年率の超過（3 経路） | 最大下落（3 経路） |
|---|---|---|
| C 合算（今の運用） | +26.47% / +23.88% / +14.29% | 6.75% / 13.28% / 16.51% |
| D4 合算＋業種の上限 4 | +25.48% / +23.94% / +13.71% | 9.31% / 13.39% / 18.19% |
| D3 合算＋業種の上限 3 | +19.86% / +26.77% / +16.86% | 9.77% / 11.44% / 17.53% |
| A M-6 単独 | +35.36% / +15.08% / +23.81% | 7.38% / 20.10% / 18.15% |

採る条件（下落を重視・ユーザー判断 2026-11-15）は「3 経路すべてで最大下落が C より小さい」かつ「超過の低下が平均 2 ポイント以内」。
どの候補も 1 つ目を満たさなかった。値の全体と参考の行は事前登録の追記節「結果（測り直し・2026-11-19）」にある。

## Considered Options

1. **今のまま（C・採用）**: 2 本の上位の和集合を等金額で持つ。業種の上限を入れても下落は 3 経路そろっては減らず、
   上限 4 は経路 +0・+1・+2 か月のすべてで C より大きかった
2. 業種の上限 4（D4）・3（D3）: 上限で飛ばした社の代わりに入る下位の社が、下落を減らさなかった
3. M-6 単独（A）: 超過の平均は高いが、経路 +1 か月で最大下落が 20.10%（C は 13.28%）と開始月の運に大きく左右される
4. 期待値の大きさで配分を変える（平均分散最適化など）: 事前登録の段階で外した。M-6 の μ̂ は順位しか検証されておらず、
   水準は未較正（`docs/MODELS.md`）

## Decision

- 保有は M-6 と M-2 の画面上位から約 10 社ずつの**和集合**とし、重複した社は 1 社として持つ
- 配分は**等金額**（1 社の重みは保有数分の 1）。そのため 1 銘柄の上限は別に置かない
- **業種の上限は置かない**

## Consequences

- `docs/VISION.md` の「保有数の目安」の行から「上限は計測してから決める」を外し、この ADR を指す
- 運用再現は参考（[ADR-0069](0069-evaluation-metrics-have-roles.md)）で、過去の経路は 1 本しかない。見直しの根拠は、
  売買の記録（`portfolio_ledger.py`・#1222）からの実際の成績と、`docs/VISION.md` の成功指標（#1221）に置く
- 参考の行（M-6 だけで 20 社・M-2* だけで 20 社）は判定に使わないと事前に決めた。判定を見てから候補に足すことはしない
  （測るなら事前登録からやり直す）
- 合算の保有数は平均 15.6〜16.3 社（2 本の一覧の重複が平均 3.7〜4.4 社）で、VISION の「約 20 社」より少なめに出る
