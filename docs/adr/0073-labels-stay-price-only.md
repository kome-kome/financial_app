# 学習と採点の答えは値上がりだけのまま（配当込みへ切り替えない）

## Status

**accepted（2026-11-11）**。#1154 の事前登録（[`docs/prereg/label-audit.md`](../prereg/label-audit.md)）の判定が
「配当 = propose_switch」になり、§4 が「学習の答えを配当込みへ切り替えるかは `PREPROCESS_VERSION` を上げるかを含めて
ADR で決める」としていたので、#1187 で決めた（ユーザー判断）。

## Context

モデルの学習・OOF の採点・探索の目的関数・運用再現は、すべて同じ答え＝52 週先の対数リターン `log(c_fut / c_snap)`
（`plugins/macro_snapshots.py` の `_build_snapshots_impl`）を使う。株価は分割調整済み・配当未調整なので、答えは
配当を含まない。

#1154（2026-11-11 の日中枠・`measure:label-audit`）は、M-4 の共通域の OOF 予測を変えずに、答えだけを配当込み
`log((c_fut + D) / c_snap)` へ差し替えて採点し直した。数値の正本は事前登録の追記節「結果」。

| M-6 − M-2 | 値上がりだけ | 配当込み | 判定の入れ替わり |
|---|---|---|---|
| 主審(a) rank-IC | +0.0436（p=0.099） | +0.0557（p=0.048） | なし |
| 主審(b) 全社の売り側spread | +0.0161（p=0.032） | +0.0186（p=0.017・正に有意） | あり |
| 副 上位10社超過の平均 | +0.0903 | +0.1027 | なし |

- 入れ替わりは主審 (b) が α = 0.025 をぎりぎりまたいだだけで、差の平均はほぼ同じ
- 向きは **M-6 の優位が広がる側**。事前登録 §1 の見立て（値上がりだけの採点は `div_yield` に +1 の制約を持つ M-2 に
  不利）とは逆で、配当込みにしても M-2 は追いつかない
- どのモデルも指標が上がる（rank-IC は M-1 +0.172→+0.190・M-2 +0.158→+0.185・M-6 +0.202→+0.241）。モデルの順位は変わらない
- D の近似は粗い。DB に配当の基準日・権利落ち日が無いので、期末日を基準日とみなし、52 週の窓の配当を年間配当 1 回分で
  近似した。`dps` が空の 4,536 行は D = 0
- `y_total − y` は全社で平均 +0.0252（中央値 +0.0242）、利回り 4% 超の帯で平均 +0.0460

## Considered Options

1. **切り替えない（答えは値上がりだけのまま）**——採用
2. **採点だけ配当込みにする（学習は今のまま）**——見送り。運用成績を配当込みで読みたくなったときに後から足せる
   （学習を変えないので `PREPROCESS_VERSION` も上がらない）
3. **学習も採点も配当込みにする**——却下。`PREPROCESS_VERSION` を上げて全モデルの学習と探索をやり直し、配当の近似も
   作り直す費用がかかるのに、モデルの比較の結論は変わらない

## Decision

1. 学習の答え・OOF の採点・探索の目的関数・運用再現の答えは、値上がりだけ（`log(c_fut / c_snap)`）のまま。
   `PREPROCESS_VERSION` は上げない
2. 理由は 3 つ:
   - 入れ替わりがぎりぎりで、結論（M-6 が上）を強める向きだった
   - **値上がりだけの採点は、今の主力（M-6）に不利な保守側の物差し**なので、値上がりだけのまま比べても「M-6 が上」と
     いう結論は甘くならない
   - 切り替えの費用（全モデルのやり直し・粗い近似の作り直し）に見合う変化が無い
3. #1155（`measure_selection_optimism`・12/4 以降）と #1157（本番予測での答え合わせ）は値上がりだけの答えで採点する。
   [`docs/prereg/selection-optimism.md`](../prereg/selection-optimism.md) の「計測の時点のパネルの答え」は値上がりだけを指す
4. 配当込みで採点し直す道具（`scripts/measure_label_audit.py`）は残す

## Consequences

- 高配当株を実際の儲け（値上がり＋配当）より低く採点する偏りは残る。モデル間の比較では M-6 側に不利に働く向きと
  分かっているので、比較の結論は保守側に出る
- 運用再現・上位10社超過などを**絶対値で**読むときは、配当の分（全社平均で 52 週あたり約 +0.025）だけ低く出ていると読む
- 見直す条件: 運用成績を配当込みで評価したくなったとき（案 2 を子 Issue で足す）、または配当の基準日・権利落ち日の
  データが入って近似が改まったとき。覆すときは新しい ADR を書く
- 52 週以内の上場廃止で答えが消える件（#1154 の判定は keep）は、パネル自体の生存者バイアスの疑いとして #1188 が扱う
- コード・表・VIEW は変えていない
