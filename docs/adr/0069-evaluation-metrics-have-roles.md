# 評価指標に役割を持たせる——rank-IC を主審に残し、上位K社の指標は拒否権、画面の並びは別に採点する

## Status

**accepted（2026-10-28）**——#1044 の規則で拒否権の K は**該当なし**。買いの拒否権は導入せず、上位K社の指標は
参考のままにする（末尾の「2026-10-28 の実測」）。proposed は 2026-10-23。Issue [#1040](https://github.com/kome-kome/financial_app/issues/1040)（親）・#1041〜#1045（子）。
本 ADR は**役割の分け方と K の決め方を固定する**ところまでを担う。拒否権に使う K は #1044 の事前登録した規則で
実測から決め、その時点で accepted へ更新する（該当する K が無ければ拒否権は導入せず、その旨を追記する）。
[ADR-0021](0021-sibling-model-candidate-menu.md)（昇格）・[ADR-0044](0044-retire-underperforming-models-by-hiding.md)（退役）・
[ADR-0063](0063-significance-is-p-below-corrected-alpha.md)（有意の規則）の判定は変えない。

## Context

### 1. 運用と評価が別のものを見ている

利用者の運用は「**M 系モデルの画面の上位数社を買う／保有の中の下位数社を売る**」。一方、モデルの評価は
すべて全断面が単位になっている。

| | 運用 | 評価 |
|---|---|---|
| 買い | 画面の上位数社 | 1か月約 1,350 社の並び全体の rank-IC（ADR-0004・0007）。分位も 5 分位＝1 分位約 270 社 |
| 売り | 保有（もともと上位から買った銘柄）の中の下位 | 全社の下位 20% と全体平均の差＝売り側spread（ADR-0022） |
| 並び | 画面の既定の並び U = μ̂ − λR（M-1 / M-2 / M-3 は λ=1.0、M-6 は 0） | μ̂ の順 |

上位数社を測る指標はコードに無い。rank-IC はすべての順位を同じ重さで数えるので、値の大半は中位の約 8 割が
決める。予測と実現の関係がどの順位でも同じ形なら、rank-IC が高いほど上位の成績も良い。しかし端の方には
データの誤り・極端な割安の罠・取引の薄い小型株が集まりやすく（#806 では M-6 の画面の上位 30 社中 23 社が
廃止・価格停止の社だった）、そこだけ壊れても rank-IC は平均に薄める。買い側 rank-IC の順位と売り側の順位が
一致しない実測（ADR-0022）も、端の質が全体の相関とは別物であることを示している。

### 2. 画面の並びと採点の並び

M-1 / M-2 / M-3 の画面は U の順に並ぶが、`oof_backtest` は μ̂ の順で採点している。全体の並びでは U と μ̂ に
有意差が無かった（#815・#816）。ただし R を引くと上位の顔ぶれが大きく入れ替わるので、上位数社では差が
出うる（未測定）。M-3 の R_macro は単一 run のスナップショットで時点再現できない（#709）。

### 3. 上位数社の指標は検定力が弱い

OOF の test 期は 3 か月おきの 10〜19 期で、52 週ラベルは隣接する約 4 期が重なる。上位 K 社の指標は 1 期あたり
K 社しか使わないので、K が小さいほどぶれが大きい。これを主審にすると、モデル間の比較の多くが「差なし」になる。

## Considered Options

1. **rank-IC 単独（現状）**——却下。運用が見ている端の質を測らない
2. **上位K社の指標を主審にする**——却下。検定力が落ち、ADR-0021 の昇格・ADR-0044 の退役の多くが判定不能になる
3. **合成スコア（複数の指標を重み付けして 1 つの点数にする）**——却下。重みに根拠が無く、どの指標で負けたかが
   見えなくなり、検定数だけが増えて補正後 α が締まる
4. **すべての採点を U の順にする**——却下。λ は利用者の好みのつまみ（ADR-0007 で探索から除外）で、λ を
   動かすたびにモデルの優劣が変わる。μ̂ で出してきた過去の判定とも比べられなくなる
5. **画面の既定を μ̂ に戻す（λ=0）**——保留。上位K社で U が得か損かを測らないまま既定を動かすことになる。
   決定 2 の実測の後に #1040 で判断する
6. **上位K社の指標を参考表示だけにする**——却下。端が大きく崩れても昇格が止まらない
7. **指標に役割を持たせ、採点を 2 種類に分ける**——採用

## Decision

### 1. 指標の役割は 3 つ

| 役割 | 指標 | 使い方 |
|---|---|---|
| 主審 | 買いは rank-IC、売りは売り側spread（どちらも今のまま） | 補正後 α で優劣を決める（ADR-0021・0063） |
| 拒否権 | 上位K社超過リターン（決定 3 の K）。売りは上位層の売り側spread（決定 4・置くかは実測後） | 候補 − 現行の期別差を主審と同じ定常ブートストラップで検定し、**有意に負なら昇格を止める**。改善の証拠には使わない。拒否権の検定は主審と別の家族で補正するので、主審の α は緩まない（止める向きにだけ効く） |
| 参考 | precision@K・上位 10% 内の rank-IC・NDCG@K・K=5/10/30 の全値・ターンオーバー・損益分岐コスト・OOF 運用再現 | 並べるだけで判定に使わない |

### 2. 採点を 2 種類に分ける

- **予想の採点**: μ̂ の順。昇格・退役・探索・比較画面の ▲▼ はこちらで、値も判定も変えない
- **画面の並びの採点**: 各プラグインの既定の λ・横軸（生の R）で作った U の順。拒否権と参考に使う。
  λ=0 のモデルでは予想の採点と同じなので出さない。M-3 の R_macro のように時点再現できない横軸では、
  「未来情報込みの上限」と明記して参考扱いにする（#709 と同じ扱い）

### 3. K は測る前に決めた規則で選ぶ

参考には K=5 / 10 / 30 を並べる。拒否権の K は #1044 で[事前登録](../prereg/)した規則で決める。規則は
**各モデル自身の上位K社超過リターンの期別系列のぶれだけ**を入力にし、モデル間の差を見ない:
MDE ＝ (z₀.₉₅ + z₀.₈₀) × √2 × SE（片側 α=0.05・検出力 80%・対比較の SE を保守側に √2 倍）とし、
**全モデルで MDE ≤ 0.5 × |系列の平均| を満たす最小の K**。該当が無ければ拒否権は導入しない。

### 4. 売りは上位層の中で測る

1 つ前の期に買いの並び（画面の並びの採点と同じ U）で上位 20% だった社の中で、売りの並びの下位 20% が
層全体の平均より劣後した幅（上位層の売り側spread・#1043）。売りスコアの −R_macro を含む版は上限として別に出す。

### 5. 範囲外

売買代金による絞り込みと、取引コストの判定への組み込みは入れない（利用者が画面の上位を飛ばさないため・#1040 で確認）。

## Consequences

- 今の判定（ADR-0021・0044・0047・0063）は何も変わらない。変わるのは、K が決まった後に昇格へ拒否権が加わることだけ
- 拒否権は止める向きにしか効かないので、主審で有意に勝っても上位K社で有意に負ける候補は採らない。
  ぶれが大きい間は拒否権がほぼ発動しないことを受け入れる（端の大きな崩れだけを止める安全網）
- 画面の並びの採点が入ると、「モデルの予測力」と「買う並びの成績」を別々に読める。画面の λ の既定を
  μ̂ に戻すかの判断材料にもなる
- 指標の数は増えるが、主審の検定数は増えない。参考は判定に入らないので多重比較の対象外
- K を変えたくなったら、事前登録の文書を凍結し直す（開封前に限る・#1007）か、新しい ADR で覆す

## 2026-10-28 の実測

日中枠で 3 本を単独に回した（コード `992080d`・いずれも exit=0）。

- **拒否権の K（#1044）**: 該当なし。どの K でも MDE が 0.5×|平均| を上回った（表は
  [事前登録の追記節](../prereg/top-k-veto.md#結果)）。決定 1 の表の「拒否権」の行のうち買いは置かない。
  決定 3 の規則のとおり、K を候補（5・10・30）の外へ広げるなら新しい ADR で覆す
- **上位層の売り側spread（#1043・`scripts/.cache/sell_in_layer.json`）**: 3 つの買いの層のどれでも、μ̂ の売り
  （M-1・M-2・M-6）は層の平均を下回る社を選べていた（期平均 +1.5〜+6.1%・正の期 71〜94%・17 期）。
  一方、sell_ranking の既定プリセットの式（μ + −R_macro）の上限版は 3 層とも 0 か負（−0.4〜−3.5%）で、
  M-6 の μ̂ より有意に悪かった（p=0.005〜0.015）。上限版は未来情報込みなので、本番の式はこれより良くはならない。
  売りに拒否権を置くかは #1040 で判断する（それまで置かない）
- **OOF 運用再現（#1045・参考）**: 上位 10 社を買い保有の下位 2 社を入れ替える運用で、全社平均に対する年率の
  超過は M-1 +2.9%・M-2 +2.2%・M-6 +27.2%（4.25 年・17 区間・コスト 10bp 後）。経路は 1 本なので判定に使わない

## 2026-10-29 の決定（#1040）

- **売りの拒否権は置かない**（ユーザー判断）。上位層の売り側spread は参考のまま残す。買いでも 17 期では
  検出力が足りず K が決まらなかったので、売りだけ置く根拠が弱い。上の実測で疑いが出た sell_ranking の既定
  プリセットの −R_macro は、拒否権ではなく既定の見直し（#1073）で扱う
- **λ の参考を足す**: `measure:top-k-veto` が同じモデル比較から、λ>0 の M-1 / M-2 について「画面の並び U −
  予想 μ̂」の上位K社超過リターンの差（`lambda_reference`）も出す。K の規則には入れない。`lambda_risk` の既定を
  変えるかの判定の規則（主は K = 10・両側 α = 0.05・有意に悪いときだけ 0 を提案）は計測の前に #1040 で固定した
- **M-1 の `lambda_risk` 既定を 0 にした**（ユーザー判断）。同日の `measure:top-k-veto`（`head_sha` `3523ffb`・19 期）の
  `lambda_reference` で、U − μ̂ の上位K社超過リターンは M-1 が K=10 で −21.6%（95%CI [−37.2%, −7.7%]・p=0.004・
  K=5 / 30 も同じ向きで有意）、M-2 は −7.8%（p=0.22・有意差なし＝据え置き）。M-3 は U の採点を作れず対象外で据え置き。
  M-1 の画面の既定の並びは μ̂ の順になり、`momentum_gate --risk-axis` の M-1 の分母も `mu_only` になった
  （`gate:risk-axis` は λ=1.0 を `--lambdas` で明示する）。拒否権の K は再計測でも該当なし
